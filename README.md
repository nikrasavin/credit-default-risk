# Credit Default Risk

Предсказание серьёзной просрочки по кредиту на данных соревнования
[Give Me Some Credit](https://www.kaggle.com/c/GiveMeSomeCredit) — 150 000 заявок.

**Статус:** в работе. Готово: разведка данных, валидация, сравнение моделей.
Дальше: выбор порога по стоимости ошибки, калибровка, интерпретация.

## Результаты на данный момент

| Модель                                       | ROC-AUC (5-fold CV) |
| -------------------------------------------- | ------------------- |
| Логистическая регрессия, сырые признаки      | 0.694 ± 0.010       |
| Логистическая регрессия + обработка аномалий | 0.813 ± 0.003       |
| Градиентный бустинг                          | 0.864 ± 0.002       |

## Ключевые находки

- Значения 96 и 98 в счётчиках просрочек — служебные коды, а не данные.
  В этих 269 строках доля дефолтов 55% против 6,7% в среднем.
- Обработка аномалий дала линейной модели +0,12 ROC-AUC и почти ничего
  градиентному бустингу: деревья устойчивы к выбросам по устройству.
- У 19,8% клиентов не указан доход; это не случайность — такие клиенты
  старше (медиана 57 против 51) и реже уходят в дефолт.
